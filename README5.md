## Theory

A context-free grammar is in **Chomsky Normal Form** when every production is either

- A → BC (exactly two non-terminals), or
- A → a (exactly one terminal).

CNF is important because it makes many algorithms tractable. The CYK parsing algorithm, for instance, relies on every rule having exactly two symbols on the right — that property lets it fill a triangular table in O(n³) time. Beyond parsing, CNF is also a stepping stone in several theoretical proofs about context-free languages.

Getting an arbitrary grammar into CNF requires five sequential clean-up steps. Each step targets one class of "offending" rules without breaking the language generated by the grammar.

| Step | What it removes | Why it matters |
|------|----------------|----------------|
| 1 | ε-productions | CYK cannot handle rules that derive the empty string |
| 2 | Unit productions A → B | Single non-terminal on the right is not allowed in CNF |
| 3 | Inaccessible symbols | Dead code in a grammar — symbols never reached from the start |
| 4 | Non-productive symbols | Symbols that can never derive any string of terminals |
| 5 | Long and mixed rules | Replace with binary rules over non-terminals only |

### Design

Two files. `cnf.py` holds the `Grammar` class with every normalization step as a method. `main.py` is the runner.

```
Grammar object
      |
      ├── eliminate_epsilon()          step 1
      ├── eliminate_unit_productions() step 2
      ├── eliminate_inaccessible()     step 3
      ├── eliminate_nonproductive()    step 4
      └── to_cnf()                     step 5
```

All five methods operate on `self.productions`, which is a `dict[str, list[list[str]]]` — each non-terminal maps to a list of right-hand sides, and each rhs is a list of symbol strings. The empty list `[]` represents ε.

### Step 1 — Eliminate ε-productions

The method first finds every **nullable** non-terminal: one whose closure under derivation includes ε. It does this by fixed-point iteration — a symbol is nullable if it directly produces ε, or if all symbols in some rule are themselves nullable.

Then, for each production containing nullable positions, every non-empty subset of those positions is used to generate a new rule with those symbols deleted. Finally the ε rules themselves are removed.

```python
def eliminate_epsilon(self):
    nullable = set()
    changed = True
    while changed:
        changed = False
        for nt, rules in self.productions.items():
            if nt in nullable:
                continue
            for rule in rules:
                if rule == [] or all(s in nullable for s in rule):
                    nullable.add(nt)
                    changed = True
                    break

    for nt in list(self.productions.keys()):
        original = list(self.productions[nt])
        for rule in original:
            positions = [i for i, s in enumerate(rule) if s in nullable]
            for k in range(1, len(positions) + 1):
                for combo in combinations(positions, k):
                    new_rule = [s for i, s in enumerate(rule) if i not in combo]
                    if new_rule:
                        self._add_rule(nt, new_rule)

    for nt in self.productions:
        self.productions[nt] = [r for r in self.productions[nt] if r]
    return nullable
```

### Step 2 — Eliminate unit productions

A unit production is A → B where B is a single non-terminal. The fix is to compute the **unit closure** of each non-terminal — the set of non-terminals reachable from it by following unit productions — and replace A's rule-set with the union of all non-unit rules from every member of that closure.

```python
def unit_reach(start_nt):
    visited = {start_nt}
    stack = [start_nt]
    while stack:
        cur = stack.pop()
        for rule in self.productions.get(cur, []):
            if (len(rule) == 1
                    and rule[0] in self.non_terminals
                    and rule[0] not in visited):
                visited.add(rule[0])
                stack.append(rule[0])
    return visited

new_p = {nt: [] for nt in self.non_terminals}
for nt in self.non_terminals:
    for sym in unit_reach(nt):
        for rule in self.productions.get(sym, []):
            is_unit = len(rule) == 1 and rule[0] in self.non_terminals
            if not is_unit and rule not in new_p[nt]:
                new_p[nt].append(rule)
self.productions = new_p
```

### Step 3 — Eliminate inaccessible symbols

A plain depth-first search starting from the start symbol collects all reachable non-terminals. Anything not in that set is deleted from `self.productions` and `self.non_terminals`.

### Step 4 — Eliminate non-productive symbols

Fixed-point iteration again: a symbol is productive if at least one of its rules consists entirely of terminals and already-productive non-terminals. Symbols that never reach that condition are removed, along with any rule that references them.

### Step 5 — Convert to CNF

Two problems remain: rules longer than two symbols, and rules where terminals appear alongside other symbols. Both are solved by introducing fresh non-terminals.

- **Terminal proxies** — for each terminal `t`, a fresh variable `Xt → t` is created; every occurrence of `t` in a non-unit rule is replaced by `Xt`.
- **Binarisation** — after terminal replacement, any rule still longer than two symbols is collapsed right-to-left: the rightmost pair `(A, B)` is replaced by a fresh variable `Xk → A B`, and this repeats until only two symbols remain. The same pair is reused if it appears in multiple rules.

```python
def to_cnf(self):
    tv = {}   # terminal → proxy NT
    pv = {}   # (A, B)   → pair NT

    def get_tv(t):
        if t not in tv:
            v = self._fresh()
            tv[t] = v
            self.non_terminals.add(v)
        return tv[t]

    def get_pv(a, b):
        if (a, b) not in pv:
            v = self._fresh()
            pv[(a, b)] = v
            self.non_terminals.add(v)
        return pv[(a, b)]

    result = {}
    for nt, rules in self.productions.items():
        result[nt] = []
        for rule in rules:
            if len(rule) == 1:
                result[nt].append(rule)
            else:
                syms = [get_tv(s) if s in self.terminals else s for s in rule]
                while len(syms) > 2:
                    v = get_pv(syms[-2], syms[-1])
                    syms = syms[:-2] + [v]
                result[nt].append(syms)

    for t, v in tv.items():
        result[v] = [[t]]
    for (a, b), v in pv.items():
        result[v] = [[a, b]]

    self.productions = result
```

A `is_cnf()` verification method checks that every production is either length-1 terminal or length-2 non-terminal-pair, and raises no false positives.

**Original grammar**

```
A → b A a | a S | a
B → A b B | B S | a | ε

D → a
S → a B | A
```

**Step 1 — ε removed** (nullable: B)

B appears in three positions across the grammar. Adding rules with B dropped:
- `S → aB` gains `S → a`
- `B → AbB` gains `B → Ab`
- `B → BS` gains `B → S`

```
A → b A a | a S | a
B → A b B | B S | a | A b | S
C → B A | A
D → a
S → a B | A | a
```

**Step 2 — unit productions removed**

Unit productions present: `S → A`, `B → S`, `C → A`.

Unit closures:
- reach(S) = {S, A}
- reach(B) = {B, S, A}
- reach(C) = {C, A}

S inherits A's non-unit rules; B inherits both S's and A's; C inherits A's.

```
A → b A a | a S | a
B → A b B | B S | a | A b | b A a | a S | a B
C → b A a | a S | a | B A
D → a
S → a B | a | b A a | a S
```

**Step 3 — inaccessible symbols removed** (C, D)

A DFS from S reaches only S, A, B. C and D are unreachable.

```
A → b A a | a S | a
B → A b B | B S | a | A b | b A a | a S | a B
S → a B | a | b A a | a S
```

**Step 4 — non-productive symbols removed** (none)

Every remaining symbol can derive a terminal string (e.g. `A → a`, `B → a`, `S → a`). Nothing is removed.

**Step 5 — Chomsky Normal Form**

New variables introduced:

## Relation to Finite Automata

CNF sits at the intersection of grammars and automata in a concrete way. The CYK algorithm that relies on CNF is structurally equivalent to a table-filling approach for nondeterministic pushdown automata: each cell in the triangular parse table corresponds to the question "which non-terminals can derive the substring from position i to position j?" — the same question a pushdown automaton's state-set answers at each step.

The normalization steps themselves also mirror automaton-theory concepts. Eliminating ε-productions mirrors the ε-closure construction used when converting an NFA to a DFA (Lab 2): both compute the set of states reachable without consuming input. Removing inaccessible symbols is the same pruning done to DFA states that are unreachable from the initial state.

## Difficulties

The trickiest part was step 2. A naive implementation replaces each unit rule A → B with B's current rules, but if B itself has unit rules they do not get expanded. The fix is to compute the transitive closure first (all non-terminals reachable via unit steps), then harvest non-unit rules from every member of that closure in one pass. Getting this order right took a rewrite.

A smaller issue arose with fresh variable naming during step 5: the same terminal pair or NT pair can appear in multiple original rules, so the code must look up an existing proxy before creating a new one. Without the caching dictionaries `tv` and `pv`, the binarisation would create duplicate variables and bloat the grammar unnecessarily.
